# Original broadsheet map series

This independently composed design uses a full-width map, serif-led news
typography, six fixed margin bands, and a proportional official-result bar. It
intentionally avoids the map-plus-sidebar-card structure of the older project
maps and the earlier Field Notes study.

The maps use the completed 2026 reporting geometry and reviewed precinct
identities. No new fuzzy matching is performed.

Rebuild from the repository root:

```bash
uv run python scripts/create-alabama-cd5-2026-original-maps.py
```
